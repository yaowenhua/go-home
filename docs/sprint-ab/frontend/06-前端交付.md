### A2 路由切换 page_view 埋点（DD-A2）

**实现**（`router/index.js`）：
```js
router.afterEach((to) => {
  const authStore = useAuthStore()
  if (!authStore.isLoggedIn) return        // DD-A2.2 匿名不发
  activityApi.reportPageView(to.fullPath).catch(() => {})  // DD-A2.4 零影响
})
```
- 时机：`afterEach` 仅在路由变化触发；beforeEach 已 await `initialize()`，此处 `isLoggedIn` 准确。
- 失败零影响：`.catch(()=>{})` 吞错，不阻塞渲染/读写，无 toast。
- 首屏刷新不触发导航故不上报（按架构口径「本期仅路由切换时不强制首屏」）。

**自测**（真实接口联调）：
- [x] 登录态 `POST /api/activity/page-view {path}` → `{"success":true,"data":{"recorded":true}}`
- [x] 匿名（无 token）→ 401（前端因 `isLoggedIn` 为假直接不调用，不产生请求）
- [x] 缺 path → 400（后端兜底，前端恒传 `to.fullPath` 不会触发）
- [x] 断网/失败：`.catch(()=>{})` 已吞，页面渲染/读写零感知
- [x] 5min 频控由后端 `logActivity` 兜底（前端仅确认调用存在）
